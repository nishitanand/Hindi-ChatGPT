Steps to run Hindi ChatGPT-

Create a new folder and place the YAML file and Jupyter Notebook file in it.

Open a terminal in that folder and run the following commands-
1. conda env create -f hindi_chatgpt.yml
2. conda activate hindi_chatgpt
3. sudo apt install ffmpeg
4. jupyter-notebook

Then open the Hindi_ChatGPT Jupyter Notebook in your browser and run it and enjoy!
